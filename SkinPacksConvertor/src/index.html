车万女仆模型包转换器

一个将 Java 版女仆模型包转换为基岩版的工具。

UUID

UUID 是模型包的唯一标识符，你可以在 UUID 生成网站 获取它。

Java 版模型包

上传 zip 模型包后点击转换。支持： TLM 女仆模型包 （含 assets/*/maid_model.json），以及 YSM 模型包 （根目录含 ysm.json，结构同 Yes Steve Model）。加密 .ysm 暂不支持。

模型包前方的序号决定游戏内的先后顺序，一个世界只能同时加载一个模型包。

YSM转换处于早期开发阶段，若遇到异常，请打开“设置-创建者”启用内容日志后进入世界，在 GitHub issue 提交错误日志。
