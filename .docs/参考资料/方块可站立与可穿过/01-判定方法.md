# 判定方法

寻路里同一格方块可能扮演不同角色，**不能**只用「引擎标不标实心」一刀切。本方法拆成三个**单格**属性，再组合成「可站立节点」。

下文「引擎」指 Bedrock 脚本 API 在方块实例上给出的只读属性（至少需要：是否空气、是否实心、是否液体、类型 id、方块状态）。

---

## 1. 四个概念

| 名称 | 含义 | 典型用途 |
| --- | --- | --- |
| **可穿过** | 实体体积可以占用该格（脚格 / 头格净空） | 站立点上方两格；起跳净空；跨沟身位采样 |
| **可支撑** | 该格**顶面**能当站立面（站在它「上面」） | 脚下地板；判断沟中间有没有踏脚 |
| **危险** | 不宜作为站立相关格（岩浆、火、可选水） | 剔除不可站节点 |
| **可站立节点** | **三格组合**，不是单格属性 | 寻路图上的一个落脚点 |

### 坐标约定

记脚部整数格为 `(x, y_foot, z)`：

```
支撑格 below = (x, y_foot - 1, z)
脚格   foot  = (x, y_foot,     z)
头格   head  = (x, y_foot + 1, z)
```

落脚点通常以**支撑格**为键（站在哪块「地板」上），而不是脚位格。

### 可站立节点（组合）

```
可站立 :=
  below 可支撑
  ∧ foot 可穿过 ∧ head 可穿过
  ∧ below / foot / head 均非危险
```

---

## 2. 输入字段

对每一格，判定前先取得：

| 字段 | 说明 |
| --- | --- |
| 类型 id | 如 `minecraft:stone`；规则里用去掉命名空间后的短名做子串匹配 |
| 是否空气 | 引擎空气标志 |
| 是否实心 | 引擎实心标志（**≠**「可站」或「不可穿」，见实验篇） |
| 是否液体 | 引擎液体标志 |
| 方块状态 | 活板门等需要，如 `open_bit`、`upside_down_bit` |

读不到方块（未加载、越界、接口失败）时：视为**未知**——不可穿过、不可支撑、不按空气处理。

---

## 3. 辅助分类（完整名单）

短名 = 类型 id 去掉 `命名空间:` 前缀。

### 3.1 栅栏 / 墙

短名含 `fence`；或（不含 sign / banner / torch 时）含 `_wall` / 以 `wall` 结尾。  
首版：身不可穿、整格不可支撑（顶部可站后置，见 03）。

### 3.2 植物薄片（身可过、不可支撑）

短名命中任一子串，或短名以 `_sapling` 结尾：

`short_grass`, `tall_grass`, `fern`, `deadbush`, `dead_bush`, `dandelion`, `poppy`, `orchid`, `allium`, `azure_bluet`, `tulip`, `oxeye`, `cornflower`, `lily_of_the_valley`, `wither_rose`, `torchflower`, `pink_petals`, `spore_blossom`, `flower`, `wheat`, `carrots`, `potatoes`, `beetroot`, `sweet_berry`, `nether_wart`, `reeds`

### 3.3 装饰薄片（身可过）

短名命中：`torch`, `_sign`, `lever`, `tripwire`, `rail`, `redstone_wire`, `button`；或含 `pressure_plate` / `carpet`。

### 3.4 关闭活板门的安装面

短名含 `trapdoor`，且状态可读，且 `open_bit` 为关：

- `upside_down_bit` 为真 → **顶装**
- 否则 → **底装**

打开、或读不到状态 → 不算「关闭」。

### 3.5 引擎易误判类（局部站立面）

短名含：`trapdoor` / `stairs` / `ladder` / `scaffolding`。  
这类不能用「实心布尔」概括；规则里单独分支，普通平移边勿盲信。

---

## 4. 危险

```
若 是否液体：
  水（短名是 water 或含 water）→ 默认算危险（可配置为不算）
  其它液体 → 危险
否则若 短名含 lava 或 fire，或短名是 magma → 危险
否则 → 不危险
```

---

## 5. 可穿过（身位净空）

按顺序判断（先命中先返回）：

1. 空气 → **可过**
2. 引擎实心 → **不可过**（优先于薄片：引擎标实心的作物不当净空）
3. 短名含 `glass` 或 `leaves` → **不可过**
4. 栅栏 / 墙 → **不可过**
5. 短名含 `stairs` / `ladder` / `scaffolding` → **不可过**
6. 活板门：仅「关闭且底装」→ **可过**；否则 **不可过**
7. 植物薄片或装饰薄片 → **可过**
8. 液体 → **不可过**（净空采样偏保守；站立由「危险」管）
9. **默认：** 非实心 → **可过**，实心 → **不可过**

默认分支含义：名单未收录、且引擎非实心的非空气方块（如光方块、结构空位一类）→ **可过**。  
因此不能写成「非空气且不在薄片名单 → 一律不可过」。

---

## 6. 可支撑（顶面可站）

按顺序：

1. 空气或液体 → **不可支撑**
2. 短名含 `pressure_plate` 或 `button` → **不可支撑**
3. 植物薄片 → **不可支撑**
4. 短名含 `torch` / `_sign` / `lever` → **不可支撑**
5. 栅栏 / 墙 → **不可支撑**（整格；顶部后置）
6. 关闭且**顶装**活板门 → **可支撑**（落脚点就是这一格）
7. 其它活板门，或楼梯 / 梯子 / 脚手架 → **不可支撑**
8. 短名含 `carpet` → **可支撑**
9. 短名含 `glass` → **可支撑**
10. 短名含 `leaves` → **不可支撑**
11. 短名含 `farmland` → **可支撑**（耕地常非实心，仍当站立面）
12. 引擎实心 → **可支撑**
13. 否则 → **不可支撑**

**底装关闭活板门：** 本格不可支撑；人站在门格里时，落脚点应记在**下方那一格**（门当薄地板，支撑面在下一格顶）。

---

## 7. 沉陷支撑

顶面低于整格，脚会陷进支撑格本身。首版仅：**可支撑且短名含 `farmland`**。  
用途：避免在耕地「再往下一格」误建落脚点。

---

## 8. 方法原则

1. **判定依赖引擎实例属性 + 类型/状态规则**，不是纯类型 id 查表。同一类型若行为随状态变（活板门），必须读状态。
2. **引擎「实心」既不是穿过权威，也不是支撑权威**（玻璃、树叶、活板门均可为非实心，行为却不同）。
3. 用类型 id 做批量缓存时：仅对「已证明与状态无关」的类型合法；其余必须读该格实体再套本篇规则。
4. 名单未覆盖的非空气方块：必须按本篇完整流程判定（通常落到默认分支），**禁止**直接当墙。
