# 实验支撑

定稿依据来自 2026-09-30～2026-10-01 的游戏内探针与玩家目视。本篇自洽说明「测了什么、否决了什么、为何锁定 01 中的规则」。

---

## 1. 目的

在落地寻路节点判定之前，用探针对比多种候选公式，选出与玩家/引擎行为一致的主干规则；特例单独列表，避免塞进「实心」一刀切。

**本阶段不做：** 精确碰撞网格重建；模组方块穷举；完整寻路实现。

---

## 2. 真值来源

| 来源 | 做法 | 本阶段角色 |
| --- | --- | --- |
| **玩家目视（G-Player）** | 创造/生存下能否站上、走进该格 | **主干锁定依据** |
| **女仆寻路（G-Maid）** | 样本地板 + 对岸目标，看女仆是否走上顶面 / 穿过 | 设计上的主真值；**矩阵未跑**（可选后补） |
| **属性日志（G-Log）** | 记录类型 id、空气/实心/液体、方块标签与状态 | 归纳名单与特例 |

单格约定：

- **可穿过：** 碰撞箱中心能进入该格体（或作脚/头净空时不挡路）。
- **可支撑：** 能稳定站在该格顶面，不掉穿。

---

## 3. 探针能力（做了什么）

游戏内临时命令（测完已卸线，规则已写入 01）：

| 能力 | 作用 |
| --- | --- |
| API 探测 | 确认运行时方块是否暴露空气 / 实心 / 液体等 |
| 单格转储 | 看向或脚下：引擎属性 + 各候选公式结果 |
| 样本矩阵 | 在脚前铺分类样本走廊（活板门用水火隔离，避免熔岩+水变黑曜石） |

## 4. 候选公式与否决

### 4.1 可穿过候选

| 候选 | 大意 | 结果 |
| --- | --- | --- |
| 仅空气 | 只有空气可过 | 不够：漏花、草、地毯等 |
| 非实心即可过 | `!实心` | **否决**（见下） |
| 空气或液体 | — | 水与「避水站立」冲突，拆到「危险」 |
| 空气 ∪ 薄片白名单 | — | **采用（主干）** |

### 4.2 可支撑候选

| 候选 | 大意 | 结果 |
| --- | --- | --- |
| 仅实心 | 实心即可站 | **否决** |
| 非空气且非液体 | — | 叶、玻璃板、矮草易误站 |
| 实心 + 非完整面黑名单 | — | 并入混合规则 |
| 实心 ∪ 玻璃 ∪ 地毯 ∪ 关底活板门等 | — | **采用** |

### 4.3 否决「实心=可站 / 非实心=可穿」的硬证据（矩阵，2026-09-30）

下列样本引擎均为 **非实心**，行为却不同：

| 方块 | 与天真公式的冲突 |
| --- | --- |
| 玻璃 | **可站**、身不可穿 |
| 橡树叶 | 不可靠支撑；不可穿 |
| 橡木栅栏 | 身不可进柱；顶部可站（几何后置） |
| 地毯 / 矮草 / 火把 | 身可过；支撑另判 |
| 梯子 | 特例 |
| 活板门（开/关、顶/底） | **全部非实心**；开合只在状态 `open_bit` |

因此：**实心不能当支撑权威，非实心也不能当穿过权威。**

### 4.4 本环境 API

| 属性 | 可用 | 备注 |
| --- | --- | --- |
| 是否空气 | 是 | |
| 是否实心 | 是 | ≠ 完整碰撞 / 可站 |
| 是否液体 | 是 | 水确认；熔岩亦非实心 |
| 方块标签 / 全部状态 | 是 | 活板门用状态区分开合与顶底 |

其它：木活板门类型 id 为 `minecraft:trapdoor`（不是 `oak_trapdoor`）；铁为 `iron_trapdoor`。水与熔岩相邻会变黑曜石，矩阵须隔离。

## 5. 玩家目视确认（2026-10-01）

| 方块 | 支撑 | 穿过 | 定稿含义 |
| --- | --- | --- | --- |
| 活板门关（底） | 是（底部≈地毯） | 视碰撞；当薄地板 | 读关闭状态；落脚点逻辑见 01 |
| 活板门开 | 侧边可站（看朝向） | 开敞侧可过 | 特例；非全格实心 |
| 楼梯 | 可爬；侧顶可站 | 台阶逻辑 | 特例 |
| 压力板 | **否** | **是** | 不可支撑、可穿过 |
| 石 / 玻璃 / 草 / 地毯 / 液体等主干 | 与 01 一致 | 一致 | **锁定** |
| 栅栏 | **顶部可站** | 身不可进柱 | 首版整格不支撑；顶部后置 |

锁定摘要：

- 活板门必须读状态；关≈地毯支撑，开≈侧边可站。
- 楼梯与开活板门同类：状态相关局部站立面。
- 压力板：不支撑、可穿过。
- 栅栏顶可站但面积随连接变 → 不挡主干定稿，见 03。

## 6. 通过标准（当时）

- 主干全高方块 + 空气 + 水/岩浆：按 01 实现。
- 楼梯 / 地毯 / 活板门等：进特例，**不并存第二套启发式**。
- 与原版生物 AI 个别边角分歧：执行失败再缓存，不在本阶段追求 100%。

| 集合 | 结果 |
| --- | --- |
| 支撑 / 穿过主干 | 玩家目视 OK → 锁定 01 |
| 组合可站立 | 由三格组合式推导 |
| 女仆 Seek 一致率 | **未测** |

---

## 7. 对批量优化的直接含义

1. 用类型名单代替逐格读块时，只能覆盖「已证明与 01 规则可互换」的类型；默认分支与特例必须保留读实体回退。
2. 「非空气且不在薄片名单 → 不可过」与 01 的默认语义冲突，会改错光方块、结构空位等。
3. 复测时对照 01 的完整规则，勿另起一套公式。
