# 女仆脚本侧结构重构 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 `TouHouLittleMaid_BP/typescripts/src/maid` 重写为 Entity 中心 + facets / events / work / ui / serialize / compat 分层，全量 TS，行为与持久化协议等价。

**Architecture:** 事件薄入口；领域以静态模块 `Facet.method(entity, …)` 提供；`compat/EntityMaid` 转发旧调用面；JSON/`MaidGenerator` 本期不动。

**Tech Stack:** TypeScript 5.x、`@minecraft/server` 2.3.0-beta、现有 `tsc` 构建（`npm run build:scripts`）。

**Spec:** `.docs/需求文档/202602 调度优化/女仆调度优化.md`

## Global Constraints

- 不新增功能（无全局女仆队列、无新农作调度、无新工作模式、无新 seek）
- 不改 `StrMaid` 编码、lore 约定、实体属性名、`thlmm:*` / `api:mode_*` 事件名
- API 形态：`Facet.method(entity, …)`；禁止默认 `Maid.fromEntity` 包装与 id→句柄缓存
- 依赖：`facets`/`serialize` ↛ `events`/`ui`/`work`；`EntityEvents` 只进 `events/`
- 验证基线：每任务结束后在仓库根执行 `npm run build:scripts`，期望 exit 0
- 注释使用中文 UTF-8；保留原函数逻辑，只搬迁/拆分
