## 1. 结论（最简可行）

```
认领前: Path.canReach(maid, destBlock)     -- 有界 A*（含 Gap 边规则一致）
   ↓ true
allocate + mount Seek + stamp(target)
   ↓
Path.follow(maid, path)：
  Walk/Jump1/Fall 段 → 临时 marker 路点 + Seek（AI）
  SprintGap 段      → 卸/暂停 Seek + impulse + 落地检测
   ↓ Fail
release + quit + free；写短时不可达缓存
```

**不做（与 huh 一致）：** SimulatedPlayer 运行时、全程脚本走路、二格爬墙跳、多段跑酷连跳。

## 3. 图与搜索参数（首版常量）

```
SEARCH_H = 16
SEARCH_V = 4
MAX_FALL = 3
GAP_MIN = 2
GAP_MAX = 4
GAP_DY ∈ [-1, +1]
COST: Walk=1, Jump1=1.3, Fall=1+0.3*Δy, SprintGap=7
```

- 节点：脚下方块顶面可站；脚/头 AABB 近似 `0.6×1.5`；禁岩浆等伤害块；水默认不可站（与现 nav avoid_water 对齐，可配置）。  
- SprintGap：轴对齐优先；每起点每水平方向最多 1 条最近合法对岸。  
- A\*：`maxExpand`（如 2000）、`maxMs`（如 8）；超时 → 不可达。

## 4. 执行状态机（落实）

```
Idle
 → FollowAI（当前边为 Walk|Jump1|Fall：stamp 临时路点 / 追 Seek）
 → PrepGap（到位起跳格、isOnGround、Seek.quit+reset、Movement.lock）
 → Impulse（clearVelocity + 单次 applyImpulse）
 → InFlight（超时 1.5s / 伤害 / 虚空 → Fail）
 → Landed（对岸容差内且着地 → Movement.unlock，接下一段）
 → Done | Fail
```

Fail 统一：`Path.cancel` → `Seek.quit` + `Seek.release(相关目标)` + `Seek.free` + `UnreachableCache.add(dest, ttl≈30s)`。

Walk 段路点：用 **`thlmt:seek_marker`**（已有）；段结束 `release`+`remove` 临时实体，避免泄漏。
