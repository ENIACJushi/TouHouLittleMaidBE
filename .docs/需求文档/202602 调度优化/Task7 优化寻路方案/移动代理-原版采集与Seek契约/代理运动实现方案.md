## 1. 生产契约（已明确）

下列三条为**权威行为**；探针与正式 `Executor` 接线均须遵守。

### 1.1 朝向

1. 起跑时 **只一次** `teleport(feet, { facingLocation, keepVelocity: true })`（起跑前不清速，与 Gap 起跳前 `clearVelocity` 区分）。
2. **之后不再用脚本改朝向**；由目标实体 + Seek **look-only**（`look_at_target`，`control_flags: ["look"]`）持续控头。
3. 冲量只负责位移，不替代转头。

| | 状态 |
| --- | --- |
| 契约 | 如上（与 `实验设计.md` §2 / §5.1 一致） |
| 探针现状 | 起跑一次 facing；挂 `slot:seek_look`（`Seek.mountLook`）；**已去掉**周期 facing |

### 1.2 代理中退档 / 组件残留

代理会切到 `thlmm:maid_basic_script_movement`（`can_walk:false`）并 `Movement.lock`。若此时退出游戏，teardown 可能来不及跑，导致禁走组残留。

**处理：**

1. `disableAutonomous` 时写动态属性 `script_move=true`；`enableAutonomous` 时清为 `false`。
2. 女仆 **再次加载**（`MaidLifeCycleEvents.onLoad` / 启动补扫描）调用 `Movement.recoverScriptMoveResidual`：仅当旗为 true 时 `enableAutonomous`（恢复站立寻路组 + unlock），避免误伤正常坐下态。

| | 状态 |
| --- | --- |
| 契约 | 残留必须在加载时恢复 |
| 实现 | 已接线（`Movement.ts` + `MaidLifeCycleEvents.onLoad`） |

### 1.3 终点抵达判定（脚本代理段，无 melee）

不用 `entityHitEntity`。同时满足：

1. **距离**：女仆到目标点的距离 ≤ **触及距**（via / goal 可与现 `ARRIVE_VIA_H` / `ARRIVE_GOAL_H` 对齐或单独常量，标定后写入，此处不拟合）。
2. **视线锥**：目标点落在女仆目视锥形范围内（目视射线与目标点的夹角或横向偏差 ≤ 阈值；阈值标定后写入）。

| | 状态 |
| --- | --- |
| 契约 | 距离触及 + 视线锥（与 `实验设计.md` §5.3 一致） |
| 探针现状 | `Arrive.checkScriptArrive`：触及 `0.75` / 竖直 `1.6` / 目视半角 `40°`（标定前临时）；成功 reason=`reach_cone` |

## 3. Walk（平地）

1. **目标巡航**  
   `targetCruise = minecraft:movement × (0.135 / 0.25)`  
   （PATHMOV@lv1 巡航 / `Level.properties[0].movement`；等级改移速时同比缩放 `maxDv`。）

2. **着地每 tick**  
   - 沿 cardinal 追 `cruise × frictionScale`  
   - 单 tick 限幅 `maxDvAccel` / `maxDvBrake`  
   - 近距（hDist &lt; 0.85）按距离降速  
   - **每 tick 抵消侧向**

3. **参数来源**  
   - 默认：摩擦初值 + 由 cruise 推导的限幅  
   - `path_proxy_tune`：calib 实测巡航 → walk 自适应 → 写入会话，供后续 `path_proxy_run`

## 4. Jump1（+1 台）

地形：平道约 4 格 → 高 1 石台 + 落点垫（与 `path_mov` 同）。

1. 水平速在巡航带（约 0.55～1.45×cruise）且距台沿约 1.55 格时起跳；最多 2 次（含重试）。
2. **一次** `clearVelocity` + 冲量：
   - **hy** = 玩家起飞（默认 **0.42**，来自 `path_pjump` / 采集日志11；有现场采样则用最新 `takeoffVy`）
   - **hx** = Gap FIT（`ImpulseTable`，plannedDist=2 / plannedDy=+1；瞄准水平距 `minH≥1.35`）
3. 空中不补；落地仍在低台可重跳一次。

日志：`PATHPROXY|CTRL,jump,…,hySrc=player_default|pjump`。

## 6. 验收对照（PATHMOV）

| 用例 | 目标 |
| --- | --- |
| walk | `ok=1`，`meanVxzSteady≈0.135`，ticks 约 60～80 |
| jump1 | `ok=1` 一次上台；`peakVy≈0.42`；`airTicks` 单段约 8 |

**已复测（采集日志12）：** Jump1 `hy=0.42`、`peakVy=0.42`、`airTicks=8`、`ok=near`（当时仍为距离抵达）；水平 takeoff 仍偏大（~0.29 vs PATHMOV 0.135）。

**锥形抵达（采集日志13）：** walk / jump1 均 `ok=1 reason=reach_cone`（walk 88t meanVxz≈0.096；jump1 52t air=8 hy=0.42 takeoffVxz≈0.289）。未 tune；半角 40° 临时门限够用。  
Walk 未 tune 时 meanVxz 常偏慢（~0.10）；需 `path_proxy_tune` 后再对照。
