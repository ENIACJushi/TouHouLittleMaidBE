## 1. 目的

部分路径原版 `navigation.walk` / Seek 追逐处理不了，需要脚本用「目标点控视角 + 冲量控位移」代理。代理前必须先采到 **原版 Walk / Jump1** 的运动学曲线，作为拟合真值。

本轮：

- **只采原版**（Seek 索敌 + 追逐含 melee），不做冲量网格、不做代理对比。
- 控制台前缀 `PATHMOV|`，一键命令见 §3。

---

## 2. 代理朝向契约（采集与后续代理共用）

1. 起跑时 **一次** `teleport(feet, { facingLocation })`，**调用前不清 `clearVelocity`**（与 Gap 起跳前清速刻意区分，避免抹掉原版起步动量）。
2. 之后由目标实体 + `look_at_target` 持续控头。
3. 冲量（后续）只负责位移，不替代转头。

### 3.1 地形（玩家朝向定轴）

| case | 地形 | marker | 成功 |
| --- | --- | --- | --- |

### 3.2 PATHMOV schema

```
PATHMOV|META,start,case=walk|jump1,trial=n,seek=on,pursue=on
PATHMOV|SMPL,case,trial,t,x,y,z,vx,vy,vz,onG,hDist,yawApprox
PATHMOV|SUM,case,trial,ok,ticks,distH,peakVy,meanVxzSteady,airTicks,reason,airTakeoffVxz=…,airMeanVxz=…,airMinVxz=…
PATHMOV|META,finish,reason,n=
```

| 字段 | 来源 |
| --- | --- |
| `vx,vy,vz` | `maid.getVelocity()` |
| `hDist` | 到目标脚位水平距 |
| `yawApprox` | 水平速度方向（度）；速度过小时用位置增量 |
| `meanVxzSteady` | 着地且未抵达时，后半程水平速均值 |
| `airTicks` / `peakVy` | Jump1（及 Walk 偶发离地）诊断 |
| `airTakeoffVxz` | 首帧离地水平速 `√(vx²+vz²)` |
| `airMeanVxz` / `airMinVxz` | 空中窗水平速均值 / 最小（Jump1 是否掐水平速） |

每 tick 打一条 `SMPL`（量可控；若限流再改为每 2 tick）。

## 4. 从曲线反推冲量节奏（分析方法，无拟合常数）

标定脚本代理时：

1. 从 `SMPL` 画 `√(vx²+vz²)`、`vy`、`onG` 对 `t`。
2. Walk：取 `meanVxzSteady` 为水平目标速；看加速段 tick 数 → 决定每 tick 补冲量幅度与频率（避免单次冲过大）。
3. Jump1：标出首次 `onG=0`～再着地窗口；读 `peakVy`、`airTakeoffVxz` / `airMeanVxz` / `airMinVxz` → 起跳与空中水平策略；落地后水平再对照 Walk 稳态。
4. **禁止**为个别失败用例手写特例常数；只从多 trial 均值/分位更新表或控制器参数。

复测结论：**稳态与空中三列跨 trial 无漂移**（jump1 空中三列三组完全一致；walk 巡航恒为 0.135；ticks/distH 仅小幅抖动）。真值可锁定，可开冲量代理原型。

### Walk

- 加速约 **15–18 tick**：水平速 0 → **0.135**，此后长段巡航。
- 全程贴地；`hDist≈0.85` 起减速，约 **0.73** 判 `near`。
- 轴对齐前进时 `yawApprox=0` 属正常。

### Jump1

- 上台前与 Walk 同型加速/巡航（`vz→0.135`）。
- 起跳首帧：`vy≈0.420`，`airTakeoffVxz=0.135`。
- 空中 **8 tick**：`vy` 自 0.42 降至负值再落地；下一 tick 水平速掉到 ~0.01，`airMeanVxz≈0.029`、`airMinVxz≈0.005`，落地后再爬回 0.135。
- 代理含义：**空中不可按地面稳态 0.135 持续喂水平冲量**，否则会比原版冲得远。

### 代理初值线索（分析方法，非整表常数）

- 平地目标水平速 ≈ **0.135 / tick**（与 `minecraft:movement` 读数对照）。
- Jump1 起跳竖直：观测首帧离地 **`vy≈0.42`** → 冲量 `hy` 的初值线索；空中水平按观测衰减（起飞 0.135 → 均值 ~0.03），勿用地面稳态补水平。
- 抵达：距离阈 0.75 本跑够用；未触发 `hit_marker`。
- 备注：`Level.movement` 脚本值为 0.25，与 `getVelocity` 巡航 **0.135** 不是同一标度；代理以采集速度为准。

## 8. 冲量代理原型（进行中）

代码：`TouHouLittleMaid_BP/typescripts/test/path/MovementProxyTest.ts`  
入口：`initMovementProxy()`。日志前缀 **`PATHPROXY|`**（schema 同 PATHMOV SUM/SMPL，另有 `CTRL,jump,…`）。

| 命令 | 作用 |
| --- | --- |
| `path_proxy_help` | 用法 |
| `path_proxy_run [walk\|jump1\|all] [trials]` | 同地形冲量代理（用会话参；未 tune 则按 movement 比值起算） |
| `path_proxy_tune` | **一次指令**自寻参：原版巡航标定→walk 自适应→jump 网格→verify |
| `path_proxy_stop` / `path_proxy_dump` | 中止 / 重打 |

### 8.1 本阶段实现

- Seek **只 mount 索敌 + stamp**，**不挂追逐**（避免原版 nav 抢走）；`tune` 的 calib 步例外挂追逐测巡航。
- **朝向契约**：起跑一次 `facingLocation` + `keepVelocity`；冲量段挂 `slot:seek_look`（`Seek.mountLook`），不再周期 facing。
- 冲量段 `disableAutonomous`（`script_move` DP 旗 + 禁走组 + lock）；teardown / **onLoad 残留恢复** `enableAutonomous`。
- **行进目标速** = 实体 `minecraft:movement` ×（PATHMOV 巡航 0.135 / lv1 movement 0.25）；等级改移速时同比缩放 `maxDv`。
- 着地：指令速 = `targetCruise × frictionScale`，单 tick 限幅 `maxDvAccel/Brake`；侧向每 tick 抵消。
- Jump1：一次冲量——**`hy` = 玩家起飞**（默认 `0.42`）；`hx` = Gap FIT；空中不补。
- 玩家起跳采集：`path_pjump` → `PATHPJUMP|`。
- **抵达契约**：触及距 + 视线锥（§5.3）；探针 `Arrive.checkScriptArrive`，成功 `reason=reach_cone`（半角 40° 标定前临时）。

### 8.5 自寻参（`path_proxy_tune`）

一次指令内完成，日志前缀 `PATHPROXY|TUNE`：

1. **calib**：平道 Seek+追逐，取 `meanVxzSteady` 为权威 `targetCruise`，并记 `cruise/movement` 比值。
2. **walk_search**：最多 8 次自适应（按稳态误差调 `frictionScale`/`maxDvAccel`），评分贴近目标巡航与 PATHMOV 时长。
3. **verify**：BEST walk 参 + Gap Jump1 各跑一轮；会话只存 walk 参（跳跃查表）。

验收仍对照 §8.2；手感轮次把 `TUNE,best` / `verify` SUM 贴回本目录日志即可。
