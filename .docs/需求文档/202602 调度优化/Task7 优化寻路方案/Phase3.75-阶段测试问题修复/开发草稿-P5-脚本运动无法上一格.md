# P5：脚本向量运动无法跳上一格高障碍

## 现象

`ScriptFollow`（脚本冲量巡航）面对一格高台/方块时，女仆只会水平顶墙，上不去。原版 FollowAI 同路径通常能迈上。

## 根因

脚本段 `can_walk:false` + `movement` 锁 0，**不会**触发原版自动上台；唯一上台路径是 `tickScriptFollow` 里的 `applyJump1Impulse`。起跳被两道门同时卡死：

1. **水平窗 `SCRIPT_JUMP_HDIST_MIN = 0.9` 过大**  
   贴在上台块立面上时，脚心到目标支撑格心水平距 ≈ `0.5 + 碰撞半径(0.3) = 0.8` **&lt; 0.9**，整段 Jump1 分支进不去。

2. **强制沿向速度落在巡航带**  
   `alongVel ∈ [0.55, 1.45]×cruise`。撞墙后水平速≈0，永远不满足；又因（1）进不了分支，只能 `tickWalkDrive`（`y:0`）继续顶墙。

几何量：半格 `0.5`、碰撞半径 `MAID_COLLISION_RADIUS`——不是失败用例拟合。

## 方案对比

| 方案 | 做法 | 取舍 |
| --- | --- | --- |
| A | 仅下调 `HDIST_MIN` | 贴墙能进分支，但仍可能因 alongVel≈0 不起跳 |
| B（推荐） | 下调 `HDIST_MIN` + 需爬升且沿速过低时允许原地起跳 | 覆盖贴墙/未起速；过远仍先平走 |
| C | ScriptFollow 临时恢复 `can_walk` 指望原版上台 | 与脚本代理禁走契约冲突 |

## 推荐方案（B）

1. `SCRIPT_JUMP_HDIST_MIN` → `0.5`（半格：立面贴齐时到格心的几何下界；贴墙 0.8 落入窗内）。
2. 需爬升且在窗内、着地时：只要 `alongVel ≤ alongMax` 即可起跳（取消「必须达到巡航下限」）；贴墙/未起速也能跳，冲量自带 hx。仍拒绝沿速过高。
3. `HDIST_MAX`、Jump 次数/重试、`PLAYER_JUMP_HY` 不动。

## 验收

1. ScriptFollow 对一格高目标支撑：能起跳并上台（贴墙顶死也能跳）。  
2. 同高平地 ScriptFollow：不无故 Jump1。  
3. 距目标水平 &gt; `HDIST_MAX`：先平走靠近，不远距离乱跳。

## 补充（能跳不上台）

一次 Jump1 后若空中不补水平，邻格上台易被立面吃掉 `hx` 掉回低台。

**约定（与 Gap 不同）：** ScriptFollow 腾空每 tick 调用同一套 `tickWalkDrive`（巡航 / 限幅 / 抵侧向与着地行走一致），持续水平向量送上台；**不用** Gap 的预计落点 `tryAirCorrect`。
