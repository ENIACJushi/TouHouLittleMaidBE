## Phase 2 — 迁入现有三条规则

对齐 `MaidGenerator/template.js` 中 `thlmm:lv1_tame` / `lv2_tame`：

| 规则 | 脚本行为 |
|------|----------|
| 主人 + 潜行 + `entityAttack` | `cancel`；`system.run` → 开菜单（复用 `Owner` + `UI.MainMenu` / 现有 interact） |
| 主人为 `damagingEntity` | `cancel` |
| 其它 | `damage *=` lv1 `0.9` / lv2 `0.75`（乘子进 `Level.properties`，如 `damageTaken: 0.9`） |

- [ ] 主人判定：优先与现网一致（`Owner.getID` / 实体 id）；注意与 JSON `is_owner` 边界差异并测  
- [ ] 等级乘子注册为内置 modifier（id 如 `level`）  
- [ ] 与 after-hurt 音效共存：cancel 的交互不播 hurt；真实扣血仍播  

**完成标准：** 手工测与现网手感一致；此时 JSON tame 组可仍挂着（双轨时可先让 JSON 乘子改为 1 / 去掉冲突，见 Phase 3）。

**双轨注意：** 若 JSON 仍带 `damage_multiplier`，会与脚本叠乘。Phase 2 末应二选一：

- 推荐：先把 JSON 乘子改成 `1`、保留菜单/免疫 JSON **或**  
- 直接进入 Phase 3 删组（需同 PR 改生成器）
