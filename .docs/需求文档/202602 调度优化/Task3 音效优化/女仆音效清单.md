## 3. `sounds.json`（自动 / 引擎侧）

文件：`TouHouLittleMaid_RP/sounds.json`

**已清空**：`thlmm:maid` 的 `hurt` / `death` 自动绑定已移除。

现改由脚本订阅（`EntityEvents`，`entityTypes: ["thlmm:maid"]`）：

| 事件 | Key | 处理 |
|------|-----|------|
| `EntityHurtAfterEvent` | `mob.thlmm.maid.hurt`（`MaidSoundType.Hurt`） | `MaidLifeCycleEvents.onHurt` |
| `EntityDieAfterEvent` | `mob.thlmm.maid.death`（`MaidSoundType.Death`） | `MaidLifeCycleEvents.onDied` |

> 与原自动音效一致：不查 mute。击杀统计仍用另一路无 `entityTypes` 的 `entityDie`（死者不一定是女仆）。

原自动绑定时：

| 实体 | 事件 | Key | 触发方 |
|------|------|-----|--------|
| `thlmm:maid` | `death` | `mob.thlmm.maid.death` | ~~引擎自动~~ → 脚本 |
| `thlmm:maid` | `hurt` | `mob.thlmm.maid.hurt` | ~~引擎自动~~ → 脚本 |

## 4. MaidGenerator / 实体 JSON 侧

源：`MaidGenerator/template.js`（生成 `TouHouLittleMaid_BP/entities/maid/maid.json`）。

### 4.1 环境事件（音效已迁脚本）

传感器仍触发 `environment:*`；事件内 **只** `set_property`，有语音的再 `trigger` → `thlmm:e*`，由 `MaidLifeCycleEvents.onEnvironmentSound` 播放（尊重 mute）。

| 实体事件 | 脚本钩子 | `MaidSoundType` |
|----------|----------|-----------------|
| `environment:temperature_warm` | `thlmm:eh` | `Hot` |
| `environment:temperature_cold` | `thlmm:ec` | `Cold` |
| `environment:weather_rain` | `thlmm:er` | `Rain` |
| `environment:weather_snow` | `thlmm:es` | `Snow` |
| `environment:morning` | `thlmm:em` | `Morning` |
| `environment:night` | `thlmm:en` | `Night` |

无音效：`environment:temperature_mild`、`environment:weather_clear`（只改 property）。

### 4.2 交互 `play_sounds`（原版 key，有意保留）

背包更换交互（剪刀卸包 / 装小中大背包）四处：

| 配置 | Key | 说明 |
|------|-----|------|
| `"play_sounds": "pop"` | 原版 `pop` | 非本包 `sound_definitions`；非女仆语音 |

## 5. TypeScript 脚本侧

播放入口：`Sound.playSound` → `playsound <name> @a <x> <y> <z>`（`typescripts/src/maid/facets/Sound.ts`）。

### 5.1 实际会播的女仆相关 key

| Key | 调用位置 | 场景 | 是否尊重 mute |
|-----|----------|------|---------------|
| `mob.thlmm.maid.tamed` | `Sound.tamed` ← `MaidLifeCycleEvents` | 驯服成功 | 仅 `disable_tamed` 跳过；**不查 mute** |
| `mob.thlmm.maid.idle` | `MaidScheduleEvents`（heal 周期 %11） | 周期闲聊 | **是**（先 `getMute`） |
| `mob.thlmm.maid.attack` | `Work.set` → `attack` 模式 | 切近战 | 否 |
| `thlmm.maid.attack` | `Work.set` → `danmaku_attack` | 切弹幕 | 否；**疑似写错**（缺 `mob.` 前缀，与定义 key 不一致） |
| `thlm.camera_use` | `MaidInteractEvents` | 相机拍照 | 否 |
| `thlm.box` | `MaidCoupledEvents.boxOpen` | 开盒 | 否 |

### 5.2 声明但当前未真正播放

| Key | 位置 | 说明 |
|-----|------|------|
| `mob.thlmm.maid.feed` | `Work.SOUND_LIS[feed]` / `[feed_animal]` | 表里有；`Work.set` **未**调用 `getSound()`，切喂食/繁殖模式不会播 |
| `Work.getSound()` | 仅定义 | 全仓库无其它调用方 |

### 5.3 静音 / 驯服抑制（非音效 key，但影响播放）
