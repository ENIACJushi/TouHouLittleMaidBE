
## 项目构建优化

目前项目有4个模块，各个分模块分别负责各自的构建：

+ MaidGenerator：生成女仆实体定义 maid.json
+ MemorizableGensokyo：生成指南书
+ SkinPacksConvertor：生成女仆皮肤和模型包转换器网站，
+ TouHouLittleMaid_BP/typescripts：行为包脚本
+ .tools：打包脚本（version、pack）

现在希望在根目录的 `.tools` 文件夹（或直接在根目录），直接使用npm指令就能执行各个模块的构建

## 落地

已采用**仓库根目录** `package.json` 薄转发方案（各模块仍各自 `npm install`，不提供聚合 `build`）。
