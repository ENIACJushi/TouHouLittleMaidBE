# Task6 实现计划：精准目标控制系统

**Goal：** 落地可复用的 **精准目标控制系统**（Seek / 锁协议 / 脚本门面 / 清恨），用 debug 目标验收。  
**不做：** 农作及其它工作模式接入；不改现网 `mode:farm` 等 family 索敌与 `Farm.ts` 等业务。

**Spec：** [huh.md](./huh.md)

**进度：Phase 0 / Phase 1 / Phase 2 已完成**（独占验收 PASS；见下）。

**已拍板：** 容量 **256**；事件 **`slot:seek_<n>`**（删旧 `tlm_seek`）；正式目标实体 **`thlmt:seek_marker`**。

**依赖后续：** 农作接入刚需 [Task7](../Task7%20优化寻路方案/huh.md)；顺序 Task6 → Task7 → 农作接线。

## 0. 结论（最简可行）

脚本 **不能** 直接指定 AI 仇恨目标：`Entity.target` 为 `read-only`。

独占锁定须走 JSON 索敌过滤器；`int_property` **只能与字面量比较**，女仆侧必须预生成 N 档互斥索敌组件。

**推荐方案：属性锁 ID + 精简 Seek**

| 侧 | Task6 做啥 | 暂不做 |
| --- | --- | --- |
| 目标实体 | debug / 通用探针实体具备 `thlmt:value` | 不改 `thlmt:farm` 等生产目标 |
| 女仆 | N 档 Seek 只过滤 `thlmt:value==seekId`；`api:reset_target` | 不改 `mode:farm|melon|…` 索敌 |
| 脚本 | `EntityMaid.Seek`：allocate / mount / quit / stamp / release / resetTarget | 不改 `Farm` / `Work` 农作进出 |

原型：`debug_fairy` + `debug_target_2`；生成器已有 `Seek.js`（需精简且脚本接线）。

## 3. 推荐设计（系统层）

### 3.1 锁协议

```
thlmt:value == -1     → 未认领
thlmt:value == seekId → 仅该 Seek 档女仆可锁定
```

### 3.2 女仆 JSON

1. 重构 Seek：组内 **仅** `follow_range`（可选）+ `nearest_attackable_target`（`must_reach: true`，建议 `reevaluate_description: true`，`persist_time: 0`）
2. 禁止 Seek 内放攻击组件
3. 事件纯化：`slot:seek_<n>` / `_quit`；**删除**旧 `tlm_seek:*` / `seek:*`；容量 **0..255**
4. 新增 `api:reset_target`
5. **保留** 现有 `mode:farm` 等 family 索敌不动

### 3.3 目标实体

- 新增 **`thlmt:seek_marker`**（带 `thlmt:value`，日后正式目标点）
- Phase 0 / 过渡验收可用 `debug_target_2`
- **不**改生产 `thlmt:farm|melon|cocoa|sugar_cane`

### 3.4 脚本门面

`EntityMaid.Seek`（名称可调整）：

1. `allocate` / `mount(seekId)` / `quit` / 释放 id
2. `stamp(target, seekId)` / `release(target)`（写 `thlmt:value`）
3. `resetTarget(maid)` → `api:reset_target`

提供 `/scriptevent` 或测试模块做双女仆独占验收；**不**挂到 `Work.set` / `Farm.search`。
